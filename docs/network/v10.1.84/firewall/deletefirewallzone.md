# Delete Custom Firewall Zone

```http
DELETE /v1/sites/{siteId}/firewall/zones/{firewallZoneId}
```

Delete a custom firewall zone from a site.

### Path Parameters

| Name | Required | Type |
| --- | --- | --- |
| `firewallZoneId` | yes | `string` |
| `siteId` | yes | `string` |

## Responses

### 200

- Response 200: No schema content available
