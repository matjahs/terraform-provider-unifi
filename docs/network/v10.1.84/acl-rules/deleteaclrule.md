# Delete ACL Rule

```http
DELETE /v1/sites/{siteId}/acl-rules/{aclRuleId}
```

Delete an existing user defined ACL rule on a site.

### Path Parameters

| Name | Required | Type |
| --- | --- | --- |
| `aclRuleId` | yes | `string` |
| `siteId` | yes | `string` |

## Responses

### 200

- Response 200: No schema content available
